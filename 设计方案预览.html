遮挡「下一张」
  • 问题 1：重置按钮固定在右下角，窄屏下压在「换一个」上，孩子想翻页会误触重置。
  • 问题 2：按钮全靠颜色区分、无图标，不识字的孩子分不清哪个是哪个。

  • 问题 4：卡片、按钮、背景全是同明度淡色块，缺层次，视觉上「平贴」。
方案 A · 推荐

糖果乐园

立体糖果按钮 + 圆点进度 + Emoji 圆形底托

☀️

日

rì
太阳
  • 立体糖果按钮：白描边 + 7px 同色厚底阴影，按下下沉 4px，触感反馈最强，幼儿最容易理解「按下去了」。
  • 圆点进度：10 个点、当前点拉长成胶囊，不识字也能看出「还剩多少」。
  • 重置移到右上角：变成 44px 的 🏠 圆钮，远离主操作区，遮挡问题彻底消失。
  • Emoji 圆形底托：图案有承载面，不再悬空，卡片更像一张贴纸。
  • 背景：奶油三色渐变 + 四角淡彩圆点，柔和不抢注意力。

  • 楷体大字：楷体笔画形态最接近教材与手写体，对幼儿识字最友好——这是三套方案里唯一用楷体的。代价是 Windows 楷体无粗体字重，只能用常规字重靠字号撑气势。
  • 绘本质感：米纸底 + 极淡竖纹 + 9px 木色画框，卡片像绘本内页，气质安静、不刺激。
  • 胶囊按钮：圆角到底、2px 深棕描边 + 柔和投影，比 A 内敛。
  • 重置弱化：变成底部居中的下划线小文字，孩子几乎不会误触（但也意味着大人要找一下）。
  • 取舍：视觉冲击力和「好玩感」弱于 A、C，更适合安静亲子共读场景。
方案 C

彩虹乐园

彩虹进度条 + 图标在上文字在下 + 彩色色带卡片

☀️

日

rì
太阳
  • 彩虹进度条：10 段彩虹色，当前段变高变实，进度感最强、最像主流儿童 App。
  • 图标在上、文字在下：84px 高的按钮，图标 30px，不识字也能靠图标操作，识别性三套中最好。
  • 白卡 + 顶部色带：卡片纯白，顶部一条当前字的主色色带，色彩集中在进度条和按钮上，主次分明。
  • 深色按钮 + 白字：对比度最高，但饱和度也最高，长时间看可能偏兴奋。
  • 取舍：彩虹条装饰性较强，若担心分散注意力可改成单色进度条。

主要风险粉彩配色偏「女孩向」的刻板印象，可调成中性色楷体无粗体字重，小屏上气势略弱彩虹条可能分散注意力；深色按钮久看偏兴奋

我的建议：3 岁幼儿优先 方案 A（按钮反馈最强、色彩最柔和、进度最直观）；若你更看重识字规范性，方案 B 的楷体值得单独采纳——也可以「A 的整体视觉 + B 的楷体汉字」混搭。方案 C 适合你想要更像市面儿童 App 的观感。
